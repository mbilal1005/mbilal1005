## Projects

**[News-rag-app](https://github.com/mbilal1005/News-rag-app)**  
FastAPI service that fetches news from RSS feeds, stores articles in PostgreSQL, indexes them with FAISS, and lets you query them in natural language. Fully Dockerized.

**[pdf-rag-app](https://github.com/mbilal1005/pdf-rag-app)**  
Ask questions about any PDF using natural language. RAG pipeline with LangChain, OpenAI, and FAISS — returns answers with source page numbers.

**[Aeroscript](https://github.com/mbilal1005/Aeroscript)**  
Domain-specific language for programming drone flight missions. Full compiler pipeline: lexer, parser, AST, static analysis, and interpreter. Written in Java with ANTLR, built with Gradle.

**Football Result Predictor** *(in progress)*  
ML model for predicting match outcomes from historical data.
