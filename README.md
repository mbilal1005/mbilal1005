## Projects

**[pdf-rag-app](https://github.com/mbilal1005/pdf-rag-app)**  
Upload any PDF and ask questions using natural language. Full RAG pipeline — LangChain + OpenAI API + vector database — served through a FastAPI backend.

**[News-rag-app](https://github.com/mbilal1005/News-rag-app)**  
Fetches, filters, and summarizes news using LLMs. Built to cut through information overload and surface what matters.

**[Aeroscript](https://github.com/mbilal1005/Aeroscript)**  
Domain-specific language for programming drone flight missions. Full language pipeline: lexer, parser, AST, static analysis, and interpreter. Written in Java with ANTLR, built with Gradle.

**Football Result Predictor** *(in progress)*  
ML model for predicting match outcomes from historical data.
